# SkyHorizon - Sistema de Emissão de Passagens

Trabalho da disciplina Programação para Dispositivos Móveis, feito em Dart com Null-Safety.

## O que tem no projeto

- Classes de apoio: `Passageiro`, `PlataformaVenda`, `Atendente`
- Classe principal `Passagem`, com construtores nomeados, parâmetros nomeados, getters/setters e métodos de negócio (emitir, cancelar, atualizar, consultar)
- Herança: `PassagemPrimeiraClasse` estende `Passagem`
- Mixins `Logger` e `Auditoria` aplicados na classe VIP
- Sobrescrita de método com `@override`

## Como rodar

```
dart main.dart
```

Todo o código está em um único arquivo: `main.dart`.
